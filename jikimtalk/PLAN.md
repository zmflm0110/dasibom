# 지킴톡 — 대회까지 계획

각 단계에 **접는 기준**이 있다. 걸리면 방향을 틀고 이유를 "결정 기록"에 적는다.

## 3분 발표

1. **문제(40초)** — 카톡감옥·방폭·떼카. 신고하려면 피해 학생이 수천 줄에서 증거를 직접 골라야 한다.
2. **시연(60초)** — 예시 파일 넣기 → 김민지 고르기 → 심각 7·주의 7·사건 6 → 체크 → 기록(지문·원문·앞뒤 대화). 폰에서 그대로.
3. **믿을 수 있는 이유(50초)** — 원문 그대로 + 앞뒤 대화 + SHA-256 / 앱은 찾기만, 체크는 사람 / 기기 밖으로 0바이트 / 일상 대화 오탐 1.1%, 규칙 정밀도 95%.
4. **정직(30초)** — 실제 또래 단톡방으로는 아직 못 쟀다. 그래서 2단계를 한다.

심사 질문:
- *"AI가 괴롭힘이라고 잘못 판단하면?"* → 판단하지 않습니다. 말의 모양으로 표시만 하고, 넣을지는 본인이 체크합니다. 보고서에 "가해자" 같은 말이 없습니다(테스트로 확인).
- *"증거를 조작할 수 있지 않나?"* → 원문을 고치지 않고, 원본 파일의 SHA-256을 적습니다. 학교는 원본 파일로 같은 값인지 확인할 수 있습니다.
- *"부모 감시 앱과 뭐가 다른가?"* → 감시가 아니라 피해 학생이 자기 손으로 여는 도구입니다. 아무것도 서버로 가지 않습니다.

## 단계

### 0. 만들기 — 끝 ✓
- [x] 해석 4모양, 유형 규칙 8가지, 사건 4가지, 공격성 모델, 기록, 위험 신호 안내
- [x] 단위·화면 테스트, 공개 데이터 측정(학습에 안 쓴 몫)

### 1. 실제 내보내기 파일 모양 — 다음 할 일
- 안드로이드·아이폰·PC·맥에서 **내 단톡방**(괴롭힘 없는 평범한 방)을 내보내 넣어 본다. "읽지 못한 줄"이 0인지, 시각·이름이 맞는지.
- **접는 기준:** 읽지 못한 줄이 1% 넘으면 그 모양을 고치기 전엔 발표하지 않는다.

### 2. 또래 말투에서 오탐 — 가장 중요
- 친구 5명에게 **괴롭힘 없는** 평범한 단톡방 파일을 받아(동의, 이름은 바꿔서) 기본 체크된 말이 몇 건인지 잰다. 친구끼리 장난 욕이 얼마나 "나를 향한 말"로 잡히나.
- **접는 기준:** 괴롭힘 없는 방에서 기본 체크가 100줄당 1건을 넘으면, 기본 체크를 "심각(협박·돈·유포·죽으라는 말)"만으로 줄인다.

### 3. 선생님·상담 선생님 검토
- 학교폭력 담당 선생님 1명, 상담 선생님 1명에게 예시 기록을 보여 준다: 이대로 받으면 도움이 되나, 빠진 것은?
- **접는 기준:** "이 형식이면 오히려 읽기 어렵다"면 기록 형식을 선생님 말대로 바꾼다.

## 결정 기록

- **모델은 판단하지 않고 표시만.** 공개 데이터는 댓글이라 단톡방과 다르다. 사람이 체크하는 구조가 틀린 판단을 막는다.
- **일상 대화를 학습에 넣었다.** 처음 모델은 "가족 여행 어디로 가지?"를 공격적이라고 봤다(일상 대화 28% 오탐). 일상 대화 1.6만 문장을 넣고 기준값을 정밀도 쪽(F0.5)으로 골라 0.64%.
- **기본 체크는 규칙만.** 규칙 정밀도 95~97%, 모델은 68~89%. 모델만 걸린 말은 "확인"으로 두고 직접 고른다.
- **NFKC를 그대로 쓰지 않는다.** NFKC는 'ㅅㅂ'·'ㅋㅋ'의 자음을 다른 글자로 바꿔 규칙이 하나도 안 걸렸다. NFC 뒤 호환 자모만 빼고 NFKC.
- **외부 글꼴 없음.** 구글 글꼴을 부르면 대화는 아니어도 요청이 밖으로 나간다. "0건"을 지키려고 기기 글꼴만 쓴다.
