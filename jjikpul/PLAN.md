# 찍풀 — 대회까지 계획

> 찍기만 하던 판서를, 떠올리는 복습으로.

각 단계에 **접는 기준**이 있다. 걸리면 방향을 틀고 이유를 "결정 기록"에 적는다.

## 대회에서 보여 줄 것 (3분)

1. **문제(30초)** — 반 친구 폰 사진첩의 판서 사진 수 vs 다시 본 횟수(설문). 선생님 한마디: "찍기만 하고 안 보잖아."
2. **근거(30초)** — 사진 찍기 손상 효과, 인출 연습·간격 반복(README 표).
3. **시연(60초)** — 칠판 찍기 → 과목 자동 → 테이프 톡톡 → 저장 1번 → 풀기(빈칸 확대 → 정답은 사진).
4. **결과(45초)** — 우리 반 실험: 떠올린 빈칸 vs 읽기만 한 빈칸, 7일 뒤 기억률. 진짜 교실 사진 OCR 표.
5. **정직(15초)** — 안 된 것: 추천 정밀도, 흘려 쓴 손글씨. 그래도 정답은 안 틀리는 이유.

심사에서 나올 질문과 답:
- *"AI가 문제 만들어 주는 앱 많던데?"* → 그 앱들은 정답을 AI가 씁니다. 찍풀은 정답이 판서 사진이라 틀릴 수 없고, 사진이 폰 밖으로 안 나갑니다.
- *"Anki랑 뭐가 달라요?"* → Anki 가림 카드는 PC에서 상자를 하나하나 그립니다. 찍풀은 수업 끝 10초, 폰에서 저장 한 번입니다. 시간표로 과목도 저절로.
- *"효과가 진짜 있어요?"* → 우리 반에서 쟀습니다(4단계 표). 한 사람 안에서 비교해 개인차를 지웠습니다.

## 단계

### 0. 만들기 — 끝 ✓
- [x] 찍기·가리기·풀기·시간표·실험·백업·오프라인
- [x] 단위 테스트, 화면 테스트(외부 요청 0건·오프라인 포함)
- [x] 그린 사진으로 OCR·추천 측정(개발용/시험용 나눔) → `eval/RESULTS.md`

### 1. 진짜 교실 사진 30장 — 다음 할 일
- 친구 5명에게 지난 한 달 판서 사진을 받는다(사람 얼굴 없는 것만, 동의받고). 과목·판 종류가 고르게.
- 핵심어는 **나 말고 친구 2명이 따로** 표시한다(한 사람 기준의 치우침을 줄이려고). 둘이 겹친 것만 정답으로.
- 같은 표(`eval/suggest-measure.ts`)로 잰다. 폰 두 대(아이폰·갤럭시 중급기)에서 한 장 OCR 시간도 잰다.
- **접는 기준:** 글자 찾기가 50% 아래면 OCR 추천을 빼고 "손가락으로 끌어 가리기"를 기본으로 바꾼다. (정답은 사진이라 앱은 그대로 쓸 수 있다.) 한 장 OCR이 10초를 넘으면 "저장 먼저, 글자 찾기는 뒤에서"로 바꾼다.

### 2. 사전 설문 — 문제가 진짜인지
- 반 친구 대상: 한 학기 판서 사진 몇 장? 시험 전에 다시 본 적? 찾다가 포기한 적?
- **접는 기준:** "찍고 다시 본다"가 대부분이면 문제 설정이 틀렸다 → "찾기"(과목별 정리) 쪽으로 무게를 옮긴다.

### 3. 2주 사용 + 실험 — 효과
- 10명 이상, 실험 모드 켜고 2주. 7일 확인까지 한 빈칸만 센다.
- 한 사람 안의 차이(떠올리기 − 읽기)를 모아 평균과 부호 검정(몇 명에게서 떠올리기가 더 높았나)을 낸다. 표본이 작으니 "효과가 있다"가 아니라 **"우리 반 n명 중 k명에게서"**로 말한다.
- 같이 잰다: 하루 평균 복습 시간, 2주 뒤에도 쓰는 사람 수(습관이 되나).
- **접는 기준:** 떠올리기 쪽이 더 높은 사람이 절반도 안 되면 결과를 그대로 발표한다. 연구와 다른 이유(채점이 후함? 빈칸이 너무 쉬움?)를 찾는 게 발표 내용이 된다.

### 4. 선생님 한 분 — 곁의 사람
- 선생님이 판서를 찍어 반 전체에 "오늘의 판서" 파일로 나눠 주는 흐름이 되는지(계정 없이 파일 하나로).
- **접는 기준:** 선생님이 5분 안에 못 하면 넣지 않는다.

## 결정 기록

- **정답은 OCR 글자가 아니라 사진 픽셀.** OCR은 평균 88%만 맞는다. 글자로 채점하면 12%는 정답이 틀린 문제가 된다. 사진을 보여 주면 틀린 정답이 0이다. 대신 채점은 스스로 한다.
- **AI 문제 생성은 안 한다.** 지어낸 문제는 틀릴 수 있고, 사진을 서버로 보내야 한다. 판서에 없는 말은 만들지 않는다.
- **tesseract 낱말 대신 줄 띄어쓰기로 잇기.** 간격으로는 못 가른다(겹침, RESULTS.md). 추천 재현율 34 → 58%.
- **추천은 덤.** 시험용에서 추천이 아끼는 누름은 사진당 1.4번. 추천보다 "찾은 낱말을 점선으로 띄워 톡 한 번에 가리기"가 누름을 더 줄인다.
- **첫 복습은 3시간 뒤.** 수업 중에 "풀 것"이 뜨지 않게, 그러나 그날 안에.
- **알림은 캘린더(.ics).** 서버 없는 웹앱은 예약 푸시를 못 한다. 서버를 두면 "사진이 밖으로 안 나간다"가 흔들린다.
